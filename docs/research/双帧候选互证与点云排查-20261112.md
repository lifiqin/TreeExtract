# 双帧候选互证与点云排查（2026-11-12）

## 结论先行

本轮加强了双帧候选、几何/纹理拒错、画幅中点计算、缓存和逐次诊断；**尚未证明默认数据的实际红圈精度提高**。默认数据中照片编号 120～170 的 51 棵树，最终版本仍是 0 棵双帧通过、51 棵回退。不能将合成测试通过或回退数量变化当作现场精度验收。

## 实现与限制

- A/B 均需完整有限相机位姿、已知同架次和非退化基线。优选自动 A 不因双帧失败而偷偷变成其他帧；手动固定和水平最近的 A 不因避人或重试而改变。
- 每帧搜索多个候选，要求双侧边缘和纹理，比较两帧共同世界高度内去趋势后的纹理，并检查交会轴心与已知树的位置及邻树归属。纹理相似、几何通过和近邻检查都**不能证明目标身份**。
- 对通过内部检查的候选段，用 A 实际 4:3 投影/移轴裁去画外部分、计算画面纵向中点，并要求 B 的观测段覆盖该高度。它是**候选段**的中点，不保证已覆盖整根可见树干。
- 拍摄者风险区是经验先验，不是人体或头皮检测；既对画幅给出提示，也拒绝落入经验风险区的 A/B 观测峰。经验区外仍可能有人。
- 未获得可靠证据时保留既有 `0.12H` 等经验高度回退，不把其说成双帧量测。历史人工偏移优先；数据/画幅/校正变化后不能沿用旧双帧缓存。
- A 读取一次，最多尝试 3 张不同 B；界面展开逐次候选数、拒绝原因和可用的几何/纹理诊断。指标不是准确率。

## 回放与测试

- 旧、新版本使用同一隔离脚本，对默认数据 120～170 逐树重放；51 棵的主帧、红圈方位和仰角一致。新版原因分布：12 主帧观测不足、15 辅帧观测不足、7 主帧中点未获辅助帧支持、16 两帧方向或树位置不一致、1 基线不足。单次本机平均调用约 1296 ms 和 1320 ms，仅作粗略性能记录。
- 独立搜索 130、140、150、160、170 的主帧邻域，共 105 次尝试，仍无可信双帧通过；另在隔离副本中放宽仅内部量测的 B 候选，51 棵仍全部回退，故未把该放宽写入生产选帧。
- 用两台相机对**同一根合成 3D 纹理树干**成像，覆盖画幅、全景接缝及 `CalV`；同时检查纯色杆、不同纹理、未知架次、邻树歧义、风险区域、错误高度及不可投影等负例。物理/投影/风险测试 170 项、双帧/最近帧测试 58 项通过。近距裁切图像端到端样例仍回退；独立纯几何测试覆盖裁切中点。
- 三套数据共 942 棵树的有完整位姿的水平最近相机结果与独立枚举一致；此测试不验证图像中的目标身份或红圈精度。测试只读原 ZIP，复制可写数据及运行时到临时目录，核对原元数据哈希和 ZIP 大小/修改时间未变。

## 原始点云排查

发现默认数据对应的 `objectsegment.ply`：69,901,455 点，含坐标、RGB、分类和 `treeid`，另有 BasePoint 坐标偏移。150 号点数与 `trunk.csv` 的 N 相同，说明两者同源；其互相一致不是独立真值。

150 号 A/B 的点云投影与深度网格显示一些辅助帧存在潜在前景遮挡，另一些未见更近的其他标签点；后者**不能证明目标可见**，因为存在稀疏、同树自遮挡、动态物体和配准不确定性。160 号在不同高度存在多个点簇，不能直接把整棵树所有低处点的 XY 中位数当作树干轴。

图像自动特征匹配实验中，大量匹配来自随相机移动的拍摄者/设备，不满足静态世界假设；因此没有据此更改 OPK 姿态模型或自动校准。用户暂时没有两帧标注截图，下一步需要可核对的 A/B 同一树干特征及可见段标注，或其它独立控制点/经验证的语义模型，才能衡量并改进真实精度。

Agisoft 的[Metashape 2.3 官方手册](https://www.agisoft.com/pdf/metashape-pro_2_3_en.pdf)说明 OPK 属于相机外方位角约定；但本项目导出结果与球面全景拼接、校平的具体约定尚未通过控制点验证，不能仅凭字段名推断应当如何完整旋转源图。
