# 双帧边缘连续候选实验（2026-11-13）

## 结论和适用范围

本轮针对一个可在合成真值中复现的观测缺陷，增加了受控实验分支。**生产默认关闭该分支，仍沿用原有双帧候选流程**；仅显式设置启动环境变量为确切的 `1` 才会在单个后端进程中开启。该实验没有解决默认真实数据的 0/51 双帧通过问题，也没有证明现场红圈更准确。真实图像缺少独立的两帧同树标注；增加候选可能增加偶然误配风险，即使后续判定阈值不变也不能把通过状态解释为准确率。

## 原因与实现

原流程在树的理论垂直 ROI 内，对一个候选列的亮度、暗度和颜色响应计算整列中位数，再选择高于中位数一定幅度的最长连续段。当真实树干占多数行时，中位数可能落在树干上，结果只保留树皮中的深色纹理块，而非完整可见段。

`src/DualFrame/TrunkObservation.cs` 增加备选观测：先在候选轴心附近寻找固定的、梯度符号相反的左右边缘；逐行要求两条边缘都保持相同符号并达到强度，取最长连续段，**不跨断裂或遮挡拼接**。只有开启实验且原观测或其外观特征不可用时，`src/DualFrame/TrunkAppearance.cs` 才尝试该分支。它仍然必须通过原有双侧边缘签名、纹理、可见段、几何、邻树歧义、拍摄者风险区和置信度检查，并不将单个边缘段当成树干身份真值。

沿用当前 `DualFrameConfig.cs` 的经验参数：搜索半径 18 像素、边缘强度至少 4 灰度级、边缘距离至少 2 像素、连续段至少 8 行。新分支要求每行两侧边缘均满足方向和强度，未减少这些下限；但它们均不是通过现场标注统计校准的阈值。新增候选意味着更大的搜索空间，原有门槛并不能消除多次比较的误匹配风险。细树干、倾斜或树皮边缘不连续、低对比度和局部遮挡仍可能失败；固定左右边缘也不适合所有树形。

同一观测读取中还拒绝了不能按 8 位 BGR/BGRA 通道读取的像素格式，避免把索引色等低位深缓冲区作为三字节像素访问。此保护不是人体检测，也不改变正常 24 / 32 位照片的算法门槛。

## 合成真值与反例

`tests/DualFramePhysicalTests.cs` 新增长可见树干样例：将已知三维树干从 0 m 绘制到 4.8 m。旧候选流程在隔离源码快照上回退为 `NoCommonVisibleTrunk`；新分支成功，所测方位误差小于 0.6°，高度与 2.4 m 真值相差不超过 0.30 m。B 帧旧响应段只覆盖约 0.75°，边缘连续段覆盖约 −10.5°～18.5°。

`tests/run_dual_physical_tests.ps1` 在两个独立后端测试进程分别验证生产默认关闭和显式开启实验：加入图证链回归后，默认关闭 **271 项**通过，实验开启 **273 项**通过。两组均包含均匀背景、单侧边缘、遮挡缺口、长无纹理竖杆、两帧不同纹理、邻树歧义、无投影、风险区、索引色图片和原有合成真值；默认关闭时新增长树干样例维持旧回退，开启后合成真值通过。近景裁切样例仍因纹理或宽度互证不足回退，不能宣称近景问题已经解决。几何回归 35 项、双帧及最近帧回归 58 项通过。合成场景不是现场真值。

### 仅用于隔离研究的实验开关

普通启动无需设置任何变量。后端进程启动时只读取一次 `TREEEXTRACT_EXPERIMENT_EDGE_CANDIDATE`，只有字面值 `1` 开启；空值、`true`、含空格值等均关闭。该状态在进程生命周期内不可变，避免同一会话中不同算法共用缓存。改变变量后需要退出应用并重新启动；不要在现场生产数据上将实验结果当作已验证的自动定位。

例如，在专门用于研究的 PowerShell 窗口中启动源码模式：

```powershell
cd .\desktop-js
$env:TREEEXTRACT_EXPERIMENT_EDGE_CANDIDATE = '1'
npm.cmd start
Remove-Item Env:TREEEXTRACT_EXPERIMENT_EDGE_CANDIDATE
```

上述设置只影响该窗口及其后续启动的子进程，不会修改系统级环境变量。退出窗口前请清除变量；切勿让常规生产启动继承该实验环境。应使用隔离数据副本开展研究。

## 真实数据隔离回放

以下对照使用了**开启实验的候选构建**，不是生产默认设置。仅使用本机数据，在系统临时目录复制可写文件和候选后端，原始全景 ZIP 只读；回放脚本核对六个小数据文件的 SHA-256 和 ZIP 大小、修改时间，均未变化。ZIP 未做完整文件哈希。

- 默认 D1 的 120～170 号：旧版与新候选均为 **0 / 51 成功、51 / 51 回退**。主帧观测失败数 12→10，辅助帧观测失败数 15→13；其余新候选仍被共同可见段或轴心一致性等后续检查拒绝。51 棵的主帧和红圈角度一致，51 张生成 JPEG 的 SHA-256 也一致。
- D2、D3 各抽 5 棵，每棵分别使用优质近帧和水平最近两种双帧模式：D2 为 1 / 10 成功，D3 为 0 / 10 成功；旧版与新候选的成功 / 回退状态一致。抽样生成的 28 张照片前后哈希一致。
- 本机这一次 D2 双帧抽样平均耗时由约 407 ms 变为 528 ms；D3 由约 613 ms 变为 629 ms。样本量小且不是隔离性能基准，只说明多一轮观测有潜在性能成本。

本轮临时证据目录：`%TEMP%\treeextract-selection-qa-oQTTaR`，以及对照目录 `%TEMP%\treeextract-qa3-iUpNw0` 和 `%TEMP%\treeextract-qa3-B60kLX`。系统临时目录可能被清理，不构成长久审计存档。现场下一步仍需要独立标注的 A/B 同树树干可见段，以及包含遮挡、邻树和拍摄者的负例，才能计算精确率、召回率及红圈偏差。
