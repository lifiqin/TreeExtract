# 当前帧最近树与边缘保形改进

## 范围

本次改动针对两个独立问题：在当前全景帧中按相机位置查找最近树，以及减轻广角画面边缘的局部形状拉伸。未修改原始全景图、树心、相机位姿或人工校正文件，也未替换根目录旧版 `TreeExtractor.exe`。

## 当前帧最近树

- 左侧「树心坐标模式」增加「定位当前帧最近树」。相机位置取当前帧对应的 `Metashape.txt` 平面坐标，优先使用 `trunk.csv` 的树干轴心；没有有效轴心时使用树心坐标。按水平距离逐棵比较，结果稳定，不设会改变“最近”定义的人为距离下限。
- 选择时保持当前全景帧，并关闭「自动选最正对树的一帧」，避免选择树后程序自动跳转到另一张照片。现有双帧旁路只在自动选帧路径工作，因此此时使用单帧或已保存的人工红圈；重新勾选自动选帧可以为该树挑选其他帧，并重新进入双帧路径。
- UI 数字控件实际表示数据行序号，现标为「序号」；照片树号取数据中的真实 `Id`。两者可能不同，状态栏会同时显示序号、ID 和水平距离。
- 最近仅是坐标意义上的最近，不保证目标在照片中未遮挡，也不保证树干和相机坐标足够准确。状态栏对疑似拍摄者入镜和小于 0.25 m 的异常近距给出提示，但不改变最近邻排序。
- 当前帧没有有效相机平面坐标时明确提示并保持原选择；不使用不明坐标系的 IMU 经纬度去伪造平面位置。

实现：`src/NearestTree.cs`、`src/MainForm.NearestTree.cs`。原有按指定树选择主帧的流程仍然保留，是与此不同的功能。

## 边缘保形

原 `Proj.cs` 中的模型是径向球面透视族，不是标准的柱面 Pannini 投影。新增默认开启的「边缘保形」：`d=1`，对应球极平面投影；关闭该选项则回退原 `d=0.5`。照片与竖版切图使用同一投影状态，切换时重新计算选帧及双帧缓存和画幅参数。

在理想球面方向的局部微分意义上，距光轴 60° 处的径向/切向尺度比由旧参数的 `1.25` 降为新参数的 `1.0`。这只说明局部各向异性形变降低，不表示所有物体尺寸、边缘放大或原始镜头/拼接误差都能被消除。球极平面投影的直线可能弯曲，画面构图也会改变；例如 4:3 画幅、垂直视场 120° 时，水平视场约从 142.63° 变为 150.36°。因此保留旧模式供对照。

另修正了广角角落位于前向半球以外、但仍处于该投影有效区域时被误判为画面中心的问题；相机与树几乎重合时，预览俯仰角也会钳到控件允许范围。

## 验证

- `tests/run_algorithm_tests.ps1`：检查两种投影下的 4:3 比例、宽视场/移轴/多俯仰角正反投影，以及最近树的轴心优先、无效输入、非连续 ID 和距离相同的情况。
- 用独立 Python 暴力遍历作为对照，检查 D1 916 帧、D2 869 帧、D3 1522 帧，共 3307 个有位姿帧；本次共 `20084` 项检查通过。该对照验证几何计算的一致性，不是人工标注的视觉正确率。
- 使用隔离数据副本做 D1/D2 集成检查：通过按钮事件保持原帧、选中正确树、显示真实 ID；投影开关可往返、位姿缺失不改变选择、异常近距给出提示，人工校正副本的哈希不变。
- 旧版和新模式的同帧示例位于 `Temp/algorithm_review_20261111/projection_comparison.png`。仍需在更多场景由使用者判断画面效果，并复测遮挡、双帧定位、识别和性能；此前 R3 QA 结果不能直接作为本版本验收结果。

## 试用版

`dist/TreeExtractor-preview-20261111/TreeExtractor.exe` 使用独立的 `data` 小文件副本；配置文件中的 `Zip` 指向本机原全景包。试用版中保存的人工校正仅写入试用版副本，不会同步到原数据目录。更换数据集时，需同时检查 `DataDir` 和 `Zip` 是否指向同一批数据。
