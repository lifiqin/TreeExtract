# 无窗口后端重构记录

> 历史记录：本文描述的是迁移前的 .NET Framework 版本；后端现已迁移到自包含 .NET 10，请以当前 `desktop-js/README.md` 和迁移报告为准。

## 改动范围

- 桌面交互仍由 Electron / JavaScript 实现。C# 后端改为单进程、串行处理 JSON 行请求，不再创建隐藏的 WinForms 窗口或控件。
- 原来混在 `MainForm` 中的会话状态和算法编排迁移到 `src/BackendSession*.cs`；全景预览位图由 `src/PanoramaRenderer.cs` 按需生成。对照表数据计算与导出保留在 `src/TreeTable.cs`，不再包含表格窗体。
- 旧 WinForms 窗口、控件、主题、鼠标事件和独立入口源码已移除。`System.Drawing` 仍用于读取、投影和绘制分析图像；它不是窗口界面。
- 仍使用原有 C# / .NET Framework 4.x、ONNX Runtime 和模型。此重构不是运行时升级，也没有改变最近相机或双帧算法的判据。

## 兼容性检查

在临时数据副本上，将旧桥接程序与重构后的桥接程序对三套数据逐项对照。每套检查启动、序号为 1 / 中间 / 最后一棵树、优质近帧与水平最近、切帧、当前帧最近树、投影和水平构图开关、垂直修正、人工红圈及重算、对照表计算。所比较的状态字段、全景/照片/切图 JPEG 的 SHA-256 和对照表行均一致。原始人工标注文件未被测试写入。

此外，项目提供 `npm.cmd run test:architecture`，检查桥接程序集不引用 `System.Windows.Forms` 且后端源码没有 WinForms 窗口入口。桥接集成测试、Electron 界面冒烟测试、便携版冒烟测试及双帧/投影回归测试用于检查数据加载、识别、保存和导出等流程。

这些检查证明重构前后的抽样行为一致，**不证明红圈或双帧结果在真实图像中的定位精度**。双帧定位仍需要人工复核，详见既有 QA 报告。
