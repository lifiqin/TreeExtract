# TreeExtract 行为保持型重构验收 · 2026-11-16

## 改了什么

| 边界 | 改动与兼容承诺 |
| --- | --- |
| 界面会话 | 全景滚轮延迟任务和树种复核共用数据、树、帧身份定义；视角变化不等于换树，上传身份仍由实际切图摘要复核。 |
| 合并界面 | 共用分析、执行的忙碌状态与异常恢复。正常取消时保留分析结果；不兼容或报告字段损坏时禁止合并。修复了异常报告可能误启用按钮的边界。 |
| 采集合并 | 萃取 IMU 覆盖计数，统一配套表的独占写入。位姿行、输出排序及字节格式不变，失败保留未完成目录，仍不覆盖已有文件。不合并 LAS，也不补造缺失姿态。 |
| 定位后端 | 合并多处六分量位姿有效性检查；桌面状态获取当前帧和位姿一次，供位姿可用性和水平距离共用。最近帧、双帧和树干轴心回退的运算与阈值不变。 |
| 工程维护 | 明确预加载 API 契约、回归测试分层与 PR 检查清单；基础测试自动发现，集成阶段不重复运行基础测试。没有升级依赖、替换模型或增加运行依赖。 |

参考 [Rsbuild 贡献指南](https://github.com/web-infra-dev/rsbuild/blob/main/CONTRIBUTING.md)和 [CloudWeGo Kitex 贡献指南](https://github.com/cloudwego/kitex/blob/develop/CONTRIBUTING.md)中的分层验证、变更说明与对应测试做法；不宣称符合字节跳动未公开的内部规范。生产代码按物理行统计净减 19 行，测试有意增加，主要收益是规则只有一处定义，不是机械压缩。

## 验证结果

- 改动前基础质量门通过。改动后以独立发布的后端运行 `scripts/verify.ps1 -Integration -NearestAll`，退出码为 0：100 项桌面基础测试、23 项 JS/桥接集成、25 项标注基础测试、3 项离线浏览器测试全部通过；.NET 协议、算法、双帧、数据保护和几何检查也通过。
- Electron 实测覆盖主界面、布局、合并结果自动加载、不兼容弹窗、全景拖动、树种复核和校正。云端调用仅使用本地模拟；没有发送真实照片或使用真实密钥。
- 三套数据独立穷举 228、275、439 棵树的水平最近帧，合计 942 棵全通过。
- 用独立的运行时和元数据副本，对比旧、新后端在三套数据及实际合并结果上的行为。每套在“优质近帧”“水平最近”两种策略分别选首、中、末三棵树；24 组会话状态一致，全景、照片、切图的 72 项 SHA-256 比对一致。全景 ZIP 只读，不重写或重打包真实合并结果。
- 对新打包目录版的隔离副本，核对 ASAR 中界面文件与源码一致、后端 DLL 与验收候选一致、自包含运行时及模型齐全。用真实 EXE 验证默认与隔离数据加载、合并入口、本地识别和隔离数据上的校正保存。
