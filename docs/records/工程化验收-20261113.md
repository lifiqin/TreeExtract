# 工程化整理与验收记录（2026-11-13）

> 这是同日较早版本的历史记录；其中 EXE 哈希和人工校正数据不代表当前状态。当前测试版请看[本地测试版验收](测试版验收-20261113.md)。

## 范围

本轮目的是让现有 Windows 桌面版更易维护，而非重新调节树木定位算法。将前端双帧及照片风险展示、JSON 行解码、双帧上下文/候选/回放按职责拆开；加强桥接进程异常处理，增加展示和协议单元测试；增加验证入口、编码规范和维护文档。修复 Windows PowerShell 5.1 在 UTF-8 控制台环境下向后端启动检查注入 BOM 导致误报失败的问题，并提供保留运行时备份的构建选项。

用户数据未作为发布内容纳入 EXE；正式发布前先构建候选并验证，然后备份旧 EXE、替换稳定路径，再对稳定路径运行烟雾测试。当前正式启动文件：`desktop-js/release-net10/TreeExtract-Portable.exe`。

### 重构前后默认数据对照

在默认 `tree` 数据的 120～170 号（共 51 条）上，比较重构前后主帧、帧序号、选帧模式、距离、方向、红圈角度、完整双帧状态与逐次诊断、照片风险和状态文本，**51 / 51 一致**；120、130、140、150、160、170 六张样例 JPEG 的 SHA-256 一致。此项只说明重构未改变比较范围内的输出，不证明标注正确。

该回放前后校验了六个原始小数据文件的 SHA-256；大型全景 ZIP 仅检查大小与修改时间未变，并非全文件哈希校验。

该轮回放为 0 / 51 双帧通过、51 / 51 回退；当时尚未接入人体/头部模型，未提供现场人工标注，不能计算定位准确率。后续本机人工校正文件有变化，不应将不同快照的统计直接比较；新的同口径验证见后续验收记录。应继续按 [双帧候选互证与点云排查](../research/双帧候选互证与点云排查-20261112.md) 的限制处理，不能把合成测试或回放一致误当作现场准确率提升。
