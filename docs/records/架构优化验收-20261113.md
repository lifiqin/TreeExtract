# 架构与可读性优化（2026-11-13）

## 本次变更

- Electron 主进程拆分为入口/窗口生命周期、统一 IPC 来源校验、树木操作、树种复核和会话协调模块。页面只通过 `preload.js` 白名单访问主进程，树木桥接方法仍由后端显式分发。
- 会话协调器集中管理确认期间的互斥与预览代次。切树、取消预览或开始独占操作后，异步返回的旧快照不会重新变成可上传预览；密钥更新、树种确认和云端分析互斥，成功、取消或异常后释放锁。
- 从界面编排中分离树列表、对照表及图片放大/焦点管理。相同树集合、搜索词与选中树在帧或视角变化时不重复重建列表；更新树集合的调用方必须替换数组引用。
- .NET 后端入口只管理控制台、UTF-8 和会话生命周期；JSON 行解析与响应编码单独放在 `DesktopProtocol.cs`。桥接方法、树木数据格式、定位/投影及模型算法未在本次有意更改。
- 运行时构建在移动目录前重新检查路径、链接和进程；本次使用保留备份模式，原 `runtime` 中的日志和输出经哈希核对保留。
- 发现直接启动 `win-unpacked` 会在候选目录生成运行输出后，已废弃该候选并另建干净候选。目录版自动化入口只接受系统临时目录内、无已有输出或配置的隔离副本，拒绝直接启动候选或用户目录；不能将废弃候选用于发布。
