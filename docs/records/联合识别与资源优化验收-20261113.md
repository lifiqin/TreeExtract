# 联合识别与资源优化验收（2026-11-13）

## 使用与安全边界

- 首次在界面输入并安全保存自己的 DeepSeek API 密钥；同一 Windows 登录用户后续无需重复输入。密钥使用 Electron 异步 `safeStorage` / Windows DPAPI 加密保存在当前用户应用数据目录，不放入源码、日志或 EXE。当前用户下的其他应用仍可能取得解密能力；换用户或 Windows 账户损坏可能需要重新配置。聊天中暴露过的密钥应先在服务商处撤销并更换。
- 一次点击“开始识别（本地 + 云端）”后，先核查与上传内容相同的干净切图并确认费用；确认后本地 ONNX 与云端视觉并行，二者完成后再发起文字综合。模型最终建议仅可使用所给七组、119 项目录中的有效“组 → 树种”，组与条目不一致或证据不足时显示不确定。人工选择和确认保存仍保留。
- 只运行了拦截网络的模拟请求，没有用真实密钥验证 DeepSeek 鉴权、余额、联网或识别效果。综合模型没有直接看到图片，它依赖视觉结果和本地识别文字，不是第三份独立的视觉证据。
- 人体/头部检测阳性时仍默认隐藏图片；未检出或不可用时按用户选择直接显示并警告，模型可能漏检头皮，人工核查不可省略。

## 启动和资源

- 单文件版每次运行会解压其运行时；目录版直接运行已展开的文件。相同机器、相同隔离数据、交替各测两次，等待树列表及全景可用：单文件版约 **13.52～13.73 秒**，目录版约 **2.49～2.88 秒**。样本少且受磁盘缓存和硬件影响，不是所有机器的保证。
- 目录版约 **481.2 MiB**、276 个文件；单文件版约 **156.2 MiB**。目录版以较多的持久磁盘空间换取不重复解压，复制时必须保留整个目录。
- 本轮隔离构建候选和临时测试目录仍有额外磁盘占用；清理其中一个候选目录的请求被当前执行环境的安全策略拒绝，因此没有继续尝试删除。临时数据可能包含现场信息，不应把它们当成可公开发布的文件。
- 遮挡热力图保留原本 10×10、100 次推理与原模型；工作数组从逐格重新分配改为复用并逐格恢复。按数组尺寸计算，每次热力图约减少 **167 MiB 的大数组分配量**，这不是常驻内存或整机物理内存降低相同数值的承诺。
- 在三套数据的六张切图上，优化前后模型输入摘要、预测类别及热力图 JPEG 摘要一致，概率差小于 `1e-7`；本机六次本地识别（含热力图）中位耗时约 **1091.5 ms → 1061.9 ms**。这是有限样本回归，不证明树种识别在真实现场准确。
- 本机采样中后端空闲 CPU 约为单核的 **0%**；后端及 Electron 多进程仍会保留数百 MiB 内存，用于全景、界面和模型。未通过关闭人体检测、降低图像分辨率或更换模型来换取资源下降。
