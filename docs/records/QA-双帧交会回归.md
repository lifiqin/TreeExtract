## 5. 覆盖率根因诊断与建议参数

> 目标：把真 `Success` 覆盖率从 **3.1%** 提到 PRD §8-A2 的 **70%** 触发线，同时守住 B1（误差反增 ≤10%）与 B2（草丛/枝杈 ≤5%）。以下均为**可执行**的调整方向，阈值集中在 `src\DualFrame\DualFrameConfig.cs`（P1-3 已满足），不得散落硬编码。

### 5.1 第一瓶颈：图像量测失败 `ObservationFailed` 140/228（61.4%）

- **定位**：`TrunkObservation.cs:154` `contrast = clamp(rawContrast / PeakContrastScale, 0, 1)`（当前 `PeakContrastScale=0.35`）、`PeakContrastMin=0.12`（`Config:60`）；`:216-220` `quality = contrast × segRatio × occFactor`（**连乘**，任一短板即趋零）。1440×720 缩略图上细树干 + 复杂背景使 `peak−median` 峰对比度普遍偏低。
- **建议**：
  1. 先在离线回放导出 `contrast` 的 **P10/P25/P50 分位数**（当前回放 CSV 未含该列，建议在 `DualFrameResult` 加 `PeakContrast` 字段并写入回放，P1-2 增强）；
  2. `PeakContrastMin`：0.12 → **0.06~0.08**（取 P10~P15 为锚），`PeakContrastScale`：0.35 → **0.20~0.25**（提升归一化后 contrast）；
  3. ROI 列宽 `±0.35·|ElT−ElB|` → **±0.5**，并允许「主峰对比度不足时取颜色判据加权次峰」的一次回退，避免直接判失败；
  4. `quality` 由连乘改为**加权和**：`0.5·contrast + 0.3·segRatio + 0.2·(1−0.15·Occ)`，消除单短板归零；
  5. **Gate**：每档参数必须同时记录 B1「修正后误差反增样本占比」，>10% 即否决。

### 5.2 第二瓶颈：交会残差过大 `ResidualTooLarge` 70/228（30.7%）

- **定位**：`ResidualMaxM=0.6m`（`Config:30`）；`DualFrameGeometry.cs:50` 的 `f_resid = 1 − residual/0.6` 共用该常量作分母。日志可见 3.18m / 3.61m / 5.04m（D2 树237）等残差，说明**不是「差一点」而是射线方向系统性不一致**（疑似 A/B 位姿坐标系/航向不统一，或 D3 跨架次污染）。
- **建议**：
  1. 分两步，**不要直接放宽**：先按残差分位数把 `ResidualMaxM` 0.6 → **1.0 / 1.5m** 做离线对照，只放「接近阈值」的样本；
  2. 对 **>2m** 的样本单独归因：日志补打 A/B 相机中心、`Wrap180(AzCamA−AzCamB)`、架次 segment 标签，先修坐标系/航向（关联 DEF-04/05）再谈阈值；
  3. `f_resid` 分母随 `ResidualMaxM` 联动（现已是同一常量，改常量即可自动联动），避免阈值放宽后置信度虚高；
  4. 对残差略超阈值但 `contrast` 高的样本，可改为「低置信度 + 限幅后仍采用」而非直接回退，但需 B3 限幅标记与 Gate。

### 5.3 置信度 `ConfMin=0.5` / `ConfW={0.35,0.25,0.25,0.15}`

- **现状**：回退态日志 `置信度=0.00` 占绝大多数（D1 213/221、D2 264/275），成功样本 7/7 刚过线（最小 0.50）；限幅折减 `×0.8`（`Engine:264`）造成 D1 1 / D2 6 / D3 5 条 `LimitExceeded`。
- **建议**：
  1. 在离线回放做 `ConfMin ∈ {0.50, 0.45, 0.40}` 三档敏感度扫描，记录「误接受率 / 误差反增率」；
  2. 限幅折减 `0.8` → **0.9**，或仅当 `|dAz|>1.5×5°` / `|dEl|>1.5×6°` 才折减，减少本可成功的样本被折到线下；
  3. **先修 DEF-05** 再评估 `f_pose` 的 0.15 权重：当前恒 1.0 等于白送 0.15 分，修好后 conf 会整体下移，需与 `ConfMin` 联动标定。

### 5.4 基线角 `BaselineAngleMinDeg=15°` / `BaselineSatDeg=35°`

- **现状**：`BaselineTooSmall` 仅 D1 2 条、D3 3 条（D2 55 条，更可能是候选池偏小）；成功样本最小基线角 D1 30.9° / D2 88.3° / D3 82.9°，**A2「成功样本 100% 达标」已满足** → **基线角不是覆盖率瓶颈**。
- **建议**：**保持 15° 下限不动**（PRD P0-2 硬约束，放宽会破坏 A2/A3）；把 `BaselineSatDeg` 35° → **45~60°**，使 `f_base` 在 30~90° 区间不饱和、置信度对大基线角仍有区分度（会略降 conf，须与 §5.3 联动标定）。

### 5.5 候选池 `NoCandidateB`（D1 仅 1 条）与 P1-1

- **建议**：启用 `ARCH §3` 的 **P1-1**：在 `DualFrameEngine.cs:84-142` 的 `SelectB` 里，池内无合格 B 时**保持 B1–B6 全部硬约束不变**、把搜索半径 ×1.6 再重筛一次；**不得放宽主帧硬约束、不得增加启动读图**（C3/E1）。D2 的 55 条 `BaselineTooSmall` 应优先用此项而非降基线角阈值来解。

### 5.6 同架次判据（关联 DEF-04）

- **建议**：短期把 `SameFlightMaxDeltaSec` 600 → **≤300s** 并对交界 ±300s 配对强制「仅记录不修正」；中期改为按 GPS 间隔 >300s 聚类生成 **segment id**，配对要求 `segmentA == segmentB`。任何改动都必须用 D3 全量 439 棵重采验证不会误伤同架次长间隔配对。
