# 最近相机与双帧红圈回归记录（2026-11-12）

## 结论摘要

- 原“优质近帧”不是严格最近：它结合距离窗口、拍摄者扇区、视场和近帧质量择优。
- 新“水平最近”模式，在全景 ZIP 存在且具有有效完整位姿的候选帧中，按树干轴心（无有效轴心时用树心）和相机的平面距离选择；该几何口径在三套数据共 942 棵树上与独立计算完全一致。
- 双帧定位仍属试验性功能。下述非随机抽样的 23 棵非人工校正树中，优质模式 23 棵全部回退，最近模式仅 1 棵通过自动判据。通过并不等于定位准确；其余回退红圈也是估计值，必须人工核验。
- 所有数据集仅供读取；标注保存和重载测试在临时副本进行，不覆盖原始 `manual_marks.csv`。测试检查了原文件及副本校正文件哈希。

## 尚需处理

当前树干量测是基于局部颜色、暗度和梯度的启发式算法。枝叶、阴影、遮挡或树号/位姿误差均可能让连续响应段不是目标树干，即使双帧几何通过也可能误判。应为三套数据建立足量、覆盖遮挡和不同距离的人工标注集，记录 A/B 图中的树 ID 与可见树干上下界，测量横向偏差、可见段中点误差、误接受率和回退率，再针对量测器和候选选择优化。未经这些真值验证，不能把此次检查当作视觉准确率验收。
