# 本地双帧观测图证接口（2026-11-13）

## 目的与限制

`dual.evidence` 是直接访问本地 JSON Lines 桥接进程的**按需 QA 接口**，不是公开网络接口，也不加入 Electron 页面 IPC 白名单。只有已有双帧结果为 `success` 且当前选择与当时计算完全对应时，才尝试返回该次**实际胜出**的 A/B 候选观测和两张分析缩图。它不重新运行候选搜索，不把最终红圈、几何交点或树心位置伪装为图像观测。

图中红色中心线和方框是两个视角实际参与胜出配对的候选段；它们仅说明候选通过当前启发式几何和纹理检查，**不证明两帧确实是同一棵树，也不证明没有人物或头皮**。全景图可能包含人物及地点信息，生成、保存或分享前必须遵守数据及隐私要求。接口只在本地按需生成，不主动上传或落盘图片。

## 请求与返回

桥接请求示例：

```json
{"id":1,"method":"dual.evidence","params":{}}
```

桥接外层仍为 `{id, ok, result, error}`。`result.state` 为 `available` 时包含：

- `treeId`、`treeIndex`、`frameA`、`frameB`、从 1 开始的 `attempt`，以及 `hashFormat`。
- `observationA` / `observationB`：每侧含 `frame`、`azimuthDeg`、`elevationTopDeg`、`elevationBottomDeg`、`widthDeg`、`azimuthOriginDeg`、`verticalCalibrationDeg`，均为当次被采纳的值；另有 `x`、`yTop`、`yBottom`、`width`、`height` 和 `analysisPixelSha256`。
- `panoA`、`panoAMarked`、`panoB`、`panoBMarked`：PNG data URL。无标记图是实际观测所用小全景的无损像素快照；标记图只添加候选线框。普通后端的小全景为 1440 × 720，**不是 4:3 矫正照片**。
- `reason` 固定为 `success_pair_observations_not_identity`，提示“候选通过不等于目标身份已确认”。

坐标使用原分析小全景的归一化坐标，横轴向右、纵轴向下：

```text
x       = wrap360(azimuthDeg - azimuthOriginDeg) / 360
yTop    = (90 - elevationTopDeg - verticalCalibrationDeg) / 180
yBottom = (90 - elevationBottomDeg - verticalCalibrationDeg) / 180
```

红线为 `x × width`，方框横向半宽为 `widthDeg / 360 × width / 2`，上下边界为 `yTop × height` 和 `yBottom × height`。横向跨接缝时在图像两端环绕绘制。由于 2 像素线宽和光栅化取整，标记像素可在计算边界附近有少量偏差；线框不是人为标注真值。

## 哈希与一致性

`hashFormat` 为 `sha256-wh32le-topdown-bgra32-v1`。哈希输入依次是：宽度、高度各一个 4 字节无符号小端整数，然后按**从上到下**的逻辑行顺序，连续写入每行 `width × 4` 个 BGRA 字节；不包含 stride 填充。只接受不透明像素；不能无损校验的格式拒绝出证。

哈希在算法实际分析 A/B 缩图时计算并与胜出观测一起缓存，不保存纹理数组或图像。接口调用时从当前数据集重读同名 A/B，使用相同缩图流程并核对两侧像素哈希；随后生成 PNG，并再次验证清图 PNG 解码后像素未改变。QA 可独立解码清图，按上述格式复算哈希。重读或编码失败时不会使用新图替代旧观测。

会话核对结果绑定的树对象及 ID、数据集标识、主辅帧、尝试序号、校正、视图和投影；校验不匹配、无源图、非成功、人工优先、关闭或未执行均返回 `state: unavailable`。这时 `treeId`、`treeIndex`、`frameA`、`frameB`、`attempt`、`hashFormat`、所有观测及图片字段均为 `null`，避免泄露上一树/帧的旧图证。`reason` 使用 `not_success`、`selection_mismatch`、`source_missing`、`analysis_pixels_changed`、`invalid_observation`、`evidence_generation_failed` 或 `evidence_size_limit`。

每个 PNG 限制 8 MiB；四张图的 JSON 转义长度和消息信封按保守上界检查，不允许超过前端 64 MiB 字符的 JSON 行上限。图证是临时内存对象，缓存命中复用原胜出观测，并不会触发二次量测。

## 验证

合成回归覆盖实际胜出候选逐字段比对、缓存命中、跨树/数据集/帧/尝试拒绝、PNG 像素哈希、篡改拒绝、负 stride、透明像素拒绝、全景接缝，以及 JSON 超长和转义上界。相关入口为 `tests/run_dual_physical_tests.ps1`；默认关闭和显式开启实验候选的模式分别运行。真实数据的图证只能用于人工核查，不是现场准确率评测。
