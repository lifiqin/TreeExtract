# 树种复核与全景交互

## 使用和人工最终决定

左侧树列表只展示树号和原始高度，并仅支持按树号搜索；不再展示或按名称搜索原始树木文件中的树种字段。原始文件没有因此修改，后台仍可能读取该字段。列表也不会自动展示已保存的人工确认树种；识别建议与人工确认请在右侧复核区域查看。

1. 首次使用时，展开“云端辅助与人工确认”，输入自己的 DeepSeek API 密钥并点击“安全保存密钥”；以后同一 Windows 用户无需重复输入。选择树和切图，点击“开始识别（本地 + 云端）”。程序先展示**与实际上传 JPEG 摘要完全一致的无树号干净切图**。请检查人体、头部、地点文字等不应上传的内容；阳性图默认隐藏，须先主动选择查看，未检出和检测不可用均不能证明没有人物或头皮。
2. 在预览中勾选已核查并继续，原生对话框再次说明上传及费用；默认操作是取消。确认后本地 18 类 ONNX 模型与云端视觉模型并行启动；未配置密钥或取消上传时仍运行本地识别。
3. 视觉模型只收到本次当前树的干净切图和七组 119 项分级目录，不收到本地识别结论。切图是本地模型使用的同一幅源图，但云端 JPEG 编码和本地模型预处理不同，不是逐字节相同的模型输入。第二次请求只发送本地和云端结果的文字，进行综合比较，不再发送图片；最终建议按“分组 → 树种”显示，并检查条目是否属于该组。
4. 界面分别展示本地结果、云端视觉结果及其不确定性、综合意见与分歧。综合是对已有结果的再次整理，不是新的独立影像证据，也不是三个模型投票。分类无法判定或列表外时不应强行选近缘物种。
5. 从用户提供的 7 组、119 项中选择最终值，也可选择“不确定”或“列表外”并填写名称。点击“人工确认并保存”，再次核对树号、名称及图像摘要并确认后才落盘；未确认时模型结果不会自动成为最终树种。切树、切帧或切图变化会清除旧建议；未保存的选择仅在当前进程中按完整身份暂存，返回同一张图才可恢复，退出后丢失。

目录原样保留用户提供的 `value` 和 `name`，并不假定本地 ONNX slug 与目录标识相同；例如本地 `xiangzhang` 和目录 `zhangshu` 不能按字符串直接等同，目录中没有的落羽杉也不会自动映射成其他种。目录是用户业务分类表，不能由程序保证植物学分类绝对正确。

## 隐私、费用和保存

云端只请求固定的 `https://api.deepseek.com/chat/completions`，使用官方文档所列的 `deepseek-flash` 视觉模型及 JSON 接口。不会主动上传全景、坐标、文件路径、其他图片或树木 ID；但上传的图像像素可能本身包含人物、招牌及位置等敏感内容，程序不承诺自动脱敏。视觉和后续文字各为一次请求，可能产生费用，实际条款和价格以 [DeepSeek 视觉文档](https://api-docs.deepseek.com/guides/vision/)和[实时计费说明](https://api-docs.deepseek.com/quick_start/pricing/)为准。

密钥通过 Electron `safeStorage` 的 Windows DPAPI 异步接口加密，存于当前用户应用数据目录的 `cloud-credentials/deepseek.dat`；不把明文写入项目、日志或 EXE。输入框保存后清空，使用时密钥仍会短暂存在于进程内存和 HTTPS 请求头中。同一 Windows 登录账户下的其他程序仍可能读取并解密；不支持跨 Windows 用户直接复用。界面允许更换或删除本机记录，删除不等于撤销云端密钥，也不保证物理擦除或清理异常退出留下的密文暂存文件。不要把密钥提交到源码、截图或日志；已泄漏密钥应在服务商处撤销并更换。

人工确认写入 Electron `userData/species-confirmations` 目录下的独立 JSON，界面显示实际文件路径。记录包含数据目录与数据集指纹组合后的 SHA-256、数据集指纹、树 ID 和序号、帧名、切图摘要、最终选择及确认时间；**不存图片、密钥或两份模型原始回答**。指纹由树心、位姿、树冠及树干元数据的内容 SHA-256 和 ZIP 中央目录的条目名、长度、CRC 组成，加载前固定、加载后复查，之后发现源文件大小或修改时间变化会要求重新加载。ZIP 未做全文件密码学哈希；这些检查不能防止同权限恶意进程伪造文件元数据或 CRC。

记录不修改树心、人工红圈或对照表文件，也不会自动同步到对照表或其他电脑。请将记录作为可能包含现场信息的数据独立备份；移动目录、替换数据、重排树心文件或改变树序号后不会自动关联旧确认，旧文件不会自动删除或迁移。覆盖旧结果前会二次确认并单独备份旧记录。记录采用独占锁、同目录临时文件和原子替换，锁内再次检查用户确认时看到的旧记录版本；损坏、不兼容、被并发修改或已锁定的记录拒绝覆盖，坏记录不阻断只读云端分析。异常退出遗留锁时，错误提示会给出锁路径；锁内记录 PID 和创建时间。须先确认没有其他实例在操作，再人工处理，程序不会仅凭锁的年龄自动删除。

云端接口使用、计费及模型可随服务商变化。未进行真实账号计费请求时，模拟 HTTP 测试只能证明协议、同意和数据边界，不证明服务可用或树种识别准确。

## 全景拖动

旧交互在后端透视帧尚未完成时对已有图像施加 CSS 平移，再替换为新透视图；平移只是平面近似，和重新投影的画面并不相同，切帧与解码时容易出现跳变。新实现不再用平移伪造透视运动，而是合并高频指针位置、串行计算并等待图像解码后提交。拖动时只请求 640×400 的全景预览，释放后恢复 960×600；两者使用相同 8:5 画幅和投影参数，标记随分辨率等比例缩放，最终红圈映射仍使用后端视角。拖动及松手渲染期间的垂直滚轮会暂存，拖动结束后应用；水平滚轮不改变视场，切换数据、树或帧后旧滚轮操作不再复用。

一次本机真实数据测试中，同一视角、预热 2 轮后交替测量 8 次，预览和完整帧从请求到图像解码的中位耗时分别约 18.9 ms 和 38.5 ms；自动拖动首次显示新帧约 241 ms，包含自动化鼠标移动过程。这不是 60 fps 保证，也不能说明所有机器上的主观卡顿已经消失。高视场边缘仍有透视拉伸；不同设备需要再次实测。

## 测试边界

`tests/species-review.test.js` 覆盖目录、请求顺序、图文隔离、无效输入、部分失败、密钥清理和独立保存；`tests/species-identity-bridge.test.js` 覆盖加载后、首次识别快照之前的数据替换；`tests/ui-species-smoke.js` 用本地拦截器替代网络，在真实桌面流程中验证预览和上传的图片摘要一致、取消、授权、人工保存、重启读取及切数据隔离。它不会向 DeepSeek 发送真实图片。`tests/ui-real-pan-smoke.js` 验证真实帧拖动的最终角度和完整分辨率，输出单机耗时；`tests/ui-layout-smoke.js` 验证拖动中不重复获取整套图片、不使用 CSS 平移及滚轮交互。上述测试不能替代植物学人工真值、真人隐私复核或真实付费 API 冒烟测试。
